## About This Project
This is my personal portfolio website, built with Google Sites. It puts
my skills, projects, experiences and story in one place, so that anyone
can see what I have learned and built, not only what my resume claims.

## Pages
- **About Me:** my introduction, education, skills, internship,
  achievements, career goals and a link to my resume
- **Blogs:** my experiences, including my cybersecurity internship
  at SkillInfyTech IT Solutions Private Limited
- **Technical Projects:** my Java and other projects, each with a
  problem statement, description, concepts used and GitHub link
- **Links to Other Accounts:** LinkedIn, GitHub and my YouTube
  self-introduction video

## Tools Used

- GitHub (project code and README files)
